# Orion

A report generation and viewing tool for open-source self-hosted projects.

## Rationale

Born from the frustrations of needing to look at tool outputs to get a full picture of CI/CD runs but having no shared standard for providing them in the PR comments.

## Goal

Allow generating, formatting and viewing reports generated by other tools.

Examples being pulumi preview diffs, test run results, deployment configuration previews, etc.

### Extendability

The tools and kinds of reports that can be viewed should be extendable with plugins.

Same goes for the medium used to store the report files.

### Portability

The tools is designed to be self hosted and used in a variety of workflows. From development to CI/CD runs, or even just as a handy platform to link fellow developers to when sharing some output.

As such, generation of reports and viewing reports is split into the two core parts, the CLI tool and the viewer app.

This allows a single hosted instance of the viewer to be shared between projects while toolchains can just download and configure the types of reports they work with.
